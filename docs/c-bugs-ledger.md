# Graphviz 16.1.0 C Bug & Hazard Ledger (`docs/c-bugs-ledger.md`)

As we port Graphviz 16.1.0 (`graphviz-16.1.0.tar.xz`) to pure, safe Rust using test-driven differential verification against `/opt/homebrew/bin/dot`, we audit the C reference implementation and document every bug, memory hazard, concurrency defect, and numerical instability we encounter and fix before/during translation.

---

## Ledger Summary

| Bug ID | Upstream C Location | Category | Severity | Status in `graphvis-rs` |
| :--- | :--- | :--- | :--- | :--- |
| **GV-BUG-001** | `lib/cgraph/scan.l` (`line_num`, `InputFile`, `Sbuf`, `lexbuf`) | Re-entrancy / Global Mutable State | **High** (Corrupts concurrent parses) | **Fixed** (State encapsulated in `Lexer<'a>`) |
| **GV-BUG-002** | `lib/common/ns.c` (`Tree_node`, `Tree_edge`, `Low`, `Lim`, `Slack`) | Re-entrancy / Global Mutable State | **Critical** (Crashes concurrent Network Simplex layouts) | **Not applicable** (`network_simplex_solve` in `crates/gv-layout/src/dot.rs` keeps all state in local variables, so there are no globals to encapsulate; there is no `SimplexSolver` type, and the loop is a simplified port of `ns.c`, capped at `NS_MAX_ITER`) |
| **GV-BUG-003** | `lib/dotgen/mincross.c` (`Root`, `GlobalMinRank`, `GlobalMaxRank`, `TE_list`, `TI_list`) | Re-entrancy / Global Mutable State | **High** (Corrupts crossing minimization across threads/workers) | **Not applicable** (mincross state lives in the local `VirtualGraph` in `crates/gv-layout/src/dot.rs`, not in globals; there is no `MincrossWorkspace` type) |
| **GV-BUG-004** | `lib/util/exit.h` (`graphviz_exit`), `lib/cgraph/agerror.c` (`AGMAX`) | Process Abort on Recoverable Error | **Critical** (Traps WASM module / kills host process) | **Fixed** (Replaced with `Result<T, GraphvizError>`) |
| **GV-BUG-005** | `lib/cgraph/grammar.y` & `lib/common/htmlparse.y` | Memory Leak on Syntax Error | **Medium** (Leaks AST/HTML strings on malformed input) | **Fixed** (RAII drop + arena-scoped allocations) |
| **GV-BUG-006** | `lib/common/splines.c` & `lib/common/arrows.c` | Numerical (`NaN` propagation on zero-length edge vectors) | **Medium** (Produces `NaN` in SVG path `d="..."` attributes) | **Fixed** (Explicit epsilon / zero-length vector guards) |
| **GV-BUG-007** | `lib/common/ns.c` (`tight_tree` / `enter_edge` floating-point slack tie-breaking) | Non-determinism / Infinite Pivot Loop | **Medium** (Pointer-address order & float drift across architectures) | **Partly addressed** (the pivot loop is capped at `NS_MAX_ITER` = 2000 iterations; leaving and entering edges are chosen by index scan order, with no pointer-address ordering; this is not a line-for-line port of `ns.c`) |
| **GV-BUG-008** | `lib/dotgen/compound.c` & `lib/dotgen/fastgr.c` | Dangling Virtual Edge / Node Pointers | **High** (Use-after-free when deleting cloned virtual edges) | **Not applicable / not yet ported** (`compound.c` is not ported, so `compound=true` edge clipping is absent; the layout code uses plain `NodeId`/`EdgeId` `u32` indices into `Vec`s instead of pointers, which are not generational, so cloned virtual edges cannot dangle) |
| **GV-BUG-009** | `lib/pathplan/shortest.c` & `lib/pathplan/route.c` | Unchecked Stack/Heap Scratch Growth & Degenerate Triangle Collinearity | **Medium** (Collinear polygon vertices can fail Pshortestpath) | **Not applicable / not yet ported** (`pathplan` and `Pshortestpath` are not ported; edge routing in `crates/gv-geom/src/splines.rs` is a simpler spline router with a collinear-control-point guard in `clip_spline_arrowheads`) |
| **GV-BUG-010** | `lib/cgraph/refstr.c` (`Refstr_t` bitfield counter overflow & global dict) | Reference Count / Thread-Safety | **Medium** (Shared static string dict is not thread-safe) | **Not applicable** (there is no global string dictionary and no `StringInterner`: names and attribute values are owned `String`s in `Graph`, so there is no shared refcount to overflow) |
| **GV-BUG-011** | `lib/common/textspan.c` & `textspan_lut.c` (`estimate_textspan_size`) | Font Alias Ignored in LUT Width Lookup | **Medium** (`"Times-Bold"` / `"Helvetica-Bold"` ignores `postscript_alias` and falls back to non-bold Times width) | **Fixed** (`resolve_metrics_and_style` consults `POSTSCRIPT_FONT_ALIASES` before LUT lookup) |
| **GV-BUG-012** | `lib/common/labels.c` (`storeline` empty line height truncation) | Integer Truncation Bug | **Low** (Empty lines cast `(int)(fontsize * 1.20)` losing `.8` pt vs non-empty lines) | **Fixed** (Consistent `f64` line spacing calculation) |
| **GV-BUG-013** | `lib/common/textspan_lut.c` (`estimate_text_width_1pt` UTF-8 byte loop) | Multi-byte UTF-8 Mis-measurement | **Medium** (Iterates `const char *` byte-by-byte, counting 1 UTF-8 codepoint as 3–4 spaces) | **Fixed** (Iterates over Rust `.chars()` Unicode scalar values) |
| **GV-BUG-014** | `lib/common/colxlate.c` (`colorxlate` permissive `sscanf` & `_Thread_local` leak) | Memory Leak & Malformed Hex Parsing | **Low** (`setColorScheme` leaks `gv_strdup` buffer; `sscanf` accepts 5-digit hex strings) | **Fixed in part** (`setColorScheme` is not ported: the colorscheme is a function argument, so nothing leaks. `colorxlate` hex parsing now deliberately follows the C `sscanf` semantics, so a 5-digit `#12345` is accepted as in C) |
